# ACQUISIZIONE-E-VISUALIZZAZIONE-DATI-GEOGRAFICI
Il progetto di tirocinio ha come obiettivo l’apprendimento del linguaggio Python e la sua integrazione con un database geografico a livello aziendale.  Il sistema implementato consente: - l’acquisizione di dati tramite una telecamera - il salvataggio delle osservazioni su database PostGIS - la visualizzazione dei risultati su mappa interattiva
